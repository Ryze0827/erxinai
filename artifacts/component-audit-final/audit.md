# Appica 逐页组件与排版验收

验收日期：2026-08-12

## 结论

- 14 / 14 个页面已完成桌面端与窄屏逐页截图复核。
- 桌面验收视口为 1862 × 982 CSS 像素；窄屏验收视口为 391 × 847 CSS 像素。
- 全部页面均为单一可见 H1、无页面级横向溢出、无破图、无可见的非 Appica 原生操作控件。
- 页面字体统一为 `Geist, Inter, ui-sans-serif, system-ui, sans-serif`，代码与密钥内容使用 Geist Mono。
- 控件、表格、日期选择、下拉、标签、状态、提示、对话框、分页、骨架屏、支付选择和密钥工具选择优先使用 Appica React 子路径组件。
- 活跃样式仅由 Appica token 与 `src/console/appica.css` 的布局校准规则负责；旧 `console.css` 与 `handoff-v1.css` 未被入口引用。

## 重点修正

- 修复概览页折线图、环图的布局约束与无障碍数据表，避免图形被放大、坐标挤压和标签堆叠。
- 修复用量记录 Token 列内容溢出；日期范围、预设范围、Tooltip、表格骨架均切换为 Appica 控件。
- 渠道状态的模型健康表改为 Appica Table；窄屏切换为标签化卡片行，不再产生 705px 横向溢出。
- 支付渠道图标改为 Appica 品牌图标，充值金额、支付方式、确认信息重新按商业结账流排版。
- 图片 API 文档的参数表改为 Appica Table，修复复制按钮重叠与窄屏标题断行。
- “使用密钥”工具改为 Appica Alert、Card、Accordion、RadioGroup 组合，移除原生 details 与手写交互控件。
- 移动端顶部栏保留完整页面标题，隐藏次要的新手引导入口，避免标题与余额挤压。
- 批量图片的刷新操作改为带文字的 Appica Button；视频工作流移除窄屏卡片内的无效空白。

## 保留的必要自定义实现

- 趋势折线、环形分布、状态时间线与热力图保留为数据可视化 SVG，因为 Appica 当前没有对应的完整图表组件；颜色、线宽、字体和留白均由角色 token 控制，并保留隐藏数据表供辅助技术读取。
- 上传头像与参考图所需的原生 file input 继续保持隐藏，仅由 Appica Button 触发。
- Appica Pagination 的 `render={<button />}` 属于组件规定的组合方式，不是独立手写操作控件。
