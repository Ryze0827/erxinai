# Raw Evidence Index

This directory stores low-processed evidence captured during repository work.
Use it for logs, command output, config snippets, review excerpts, and other raw artifacts that may later support repository knowledge.

## Rules

- Keep entries close to the original evidence.
- Do not promote raw evidence directly into repository-wide rules without distillation.
- Prefer linking to raw evidence from `learning-journal.md`, source layers, or the wiki index when a fact depends on it.
